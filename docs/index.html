Visual grounding research

Do Visual Grounding Decoders Need Feed-Forward Networks?

A controlled study of what happens when the FFNs are removed from a small grounding decoder operating over frozen vision-language features.

Read the paper · Browse the repository · LaTeX source

Premise

Visual grounding takes an image and a phrase such as “the child beside the red chair” and returns one bounding box. Standard Transformer grounding heads use attention followed by a token-wise feed-forward network in every block.

Our question is narrower: if a pretrained vision-language model has already encoded the objects, language, and spatial context, does the small task-specific decoder still need those FFNs? We freeze the backbone and change only the decoder.

This is not a fully attention-only VLM. The frozen backbone keeps all of its pretrained FFNs.

Why SigLIP 2?

We chose SigLIP 2 Base/16 at 384 px as the primary frozen backbone for four practical reasons:

  • its training explicitly improves localization and dense visual features;
  • it produces a useful 24 × 24 grid of 576 spatial image tokens;
  • the public checkpoint is ungated and small enough to freeze while training only a compact decoder;
  • strong frozen features make the experiment about the decoder, rather than a weak visual representation.

We also ran a one-seed CLIP L/14@336 control. It has the same 24 × 24 patch grid, so the decoder geometry stays fixed while the representation family changes.

Datasets and composition

The evaluation moves from standard grounding to adversarial and controlled compositional references. Test datasets never choose the architecture, checkpoints, threshold, or plots.

DatasetRoleWhat it tests
RefCOCOg UMDPrimary, 3 seeds9,602 standard test expressions, plus a predeclared direct-versus-logical comparison and modality shuffles.
RefCOCO UNCReplication, seed 0A classic referring-expression dataset check under the same decoder design.

FineCops-RefControlled composition, 9,605 rowsOfficial difficulty levels and tuple types such as zero-hop, one-hop, two-hop, conjunction, and same-attribute references.

FineCops is the key composition test. Its tuple types describe how many relations or constraints connect the referring phrase to the target. We use those official fields as released; we do not invent semantic labels after seeing model errors.

Method

One learned query alternates cross-attention to text and image tokens. The final query scores all 576 image patches, producing a probability distribution that is converted to one box.

  1. A4: four attention-only blocks, 2.64M trainable parameters.
  2. S4: the same four blocks with a GELU FFN residual after attention, 4.74M parameters.
  3. A8: eight attention-only blocks, 4.75M parameters. This tests whether attention depth can use roughly the same parameter budget as S4.

The box-mass threshold is selected once on validation and frozen at τ = 0.8. Three-seed comparisons average paired outputs per example, then use 10,000 image-clustered bootstrap replicates.

Conclusion

For this small decoder over frozen VLM features, FFNs are often dispensable. Removing them at fixed depth preserves standard and adversarial grounding, while FineCops reveals a small compositional deficit.

That deficit is recovered when the FFN parameter budget is reallocated into additional attention depth. The supported claim is about decoder capacity allocation, not universal FFN removal and not a fully attention-only VLM.
