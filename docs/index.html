Do Visual Grounding Decoders Need Feed-Forward Networks?

A controlled study over frozen vision-language features

Tarun Tomar
Single-query referring-expression grounding
Read the manuscript PDF · Code and evidence

Question

Once a VLM has encoded image and language context, does a small grounding head still need an FFN?

We compare a four-block attention-only decoder (A4), the same four-block decoder with FFN residuals (S4), and an eight-block attention-only capacity control (A8). The VLM backbone remains frozen in every condition.

Main result. Fixed-depth A4 is broadly competitive on standard and adversarial grounding. FineCops-Ref exposes a small A4 deficit, but A8 recovers it. The released difficulty labels do not show a monotonic hard-example boundary.

Method

One causal intervention, shared everywhere else

Frozen inputs

SigLIP2 image and text features are projected to width 256. The backbone retains its pretrained FFNs.

Shared output

One learned query produces a 24×24 patch distribution. A frozen mass rule converts it to one box.

Locked evaluation

tau = 0.8, paired image-clustered bootstrap, 10,000 replicates, seed 20260812.

Interpretation

A narrow decoder result, released with its boundaries

  • This is not an attention-only VLM result: frozen backbones retain their FFNs.
  • A8 recovery identifies a viable capacity reallocation, not an FFN mechanism proof.
  • RefCOCO and CLIP are seed-0/one-seed descriptive replications.
  • Raw licensed images, provider-local checkpoints, and qualitative box exports are not in Git.
